# Security policies

Drafts and approved versions of the company's security policies (skill `security-policy`,
CIS Controls v8.1 IG1 and NIST CSF 2.0), e.g. `information-security-policy.md`,
`access-control.md`, `secrets-management.md`, `vulnerability-disclosure.md`,
`incident-response-plan.md`, `backup-and-recovery.md`. Each policy carries a version, status
(draft / approved / superseded), approval date and next review date in its front-matter, and is
listed in `ai-team/company/documents.md`. The legal-compliance side of a policy belongs to the
lawyer member.
