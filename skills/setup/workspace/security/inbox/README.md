# Inbox

Drop documents here for the AI security engineer: customer security questionnaires, pen-test or
audit reports, alerts from your cloud or code host, vendor security notices. After review the
file stays here; the result goes to `ai-team/security/reviews/`, `research/` or `incidents/`.

This folder may contain vulnerability details and personal data — don't sync it to public places.
Don't drop files containing live secrets; if one lands here, treat the secret as leaked.
